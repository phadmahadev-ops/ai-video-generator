# Contributing

Thanks for helping! Ye repo free tools collect karta hai — sabka contribution
welcome hai.

## Kaise contribute kare

1. Fork karo
2. Naya branch: `git checkout -b feat/your-change`
3. Changes karo (script/notebook/docs)
4. Notebook me cell **check** karna (kaggle/colab syntax)
5. Commit + Push
6. Pull Request kholo

## Rules

- Paths hardcode mat karo (env vars use karo)
- Hinglish/English dono me helpful notes chalta hai
- External notebooks copy karte waqt **attribution** zaroori
- Secrets/photos private mat daalo
